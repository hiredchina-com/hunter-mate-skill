# 示例:BD 销售方案报告

## 场景

BD 同事准备拜访某客户,需要整理历史相似客户案例与可匹配人才,生成销售方案。

## Agent 执行流程

1. 输入客户公司:

```bash
hunter-mate report sales <customer-id>
```

2. CLI 返回原始数据:
   - 客户基本信息
   - 历史相似客户(行业、规模、职位类型)
   - 该客户历史 JobCase 与推荐记录
   - 当前人才池中可匹配的亮点人才

3. 使用本地 LLM 生成销售方案报告:
   - 客户画像与痛点
   - 历史成功案例
   - 推荐服务套餐
   - 预期交付节奏

4. 输出 Markdown/PDF,供用户编辑后发送。

## 用户可能说的话

- "帮我写个方案给这个客户"
- "这个客户之前我们做过什么类似案例"
- "给我们和客户开会用的材料"
